# Logos clients — bandeau "Ils nous font confiance"

Ce dossier doit contenir les fichiers suivants, référencés par `clients` dans `script.js` :

- `veolia.svg`
- `sncf.svg`
- `pathe.svg`
- `epitech.svg`

Je n'ai fabriqué aucun de ces fichiers : ce sont des logos de marques tierces, je ne
peux pas les générer ni les télécharger moi-même. Dépose ici les fichiers officiels
(de préférence en SVG, fond transparent) — le bandeau les affichera automatiquement
dès qu'ils seront présents, sans autre modification de code.

En attendant, chaque logo manquant s'affiche en repli sous forme de nom de marque en
texte (géré automatiquement dans `script.js`, fonction `renderClientsBand`).
