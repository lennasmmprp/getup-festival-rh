# Images du site

Ce dossier doit contenir :

- `qualiopi.png` — le logo officiel de certification Qualiopi, utilisé dans le
  footer (`index.html`). Je n'ai fabriqué aucun logo de certification : c'est
  un badge officiel tiers, à te procurer auprès de ton organisme certificateur
  (ou sur le site officiel Qualiopi) et à déposer ici tel quel.

En attendant, le footer affiche automatiquement un repli textuel
(« Certifié Qualiopi ») à la place du logo manquant, sans casser la mise en
page ni afficher une icône d'image cassée.
